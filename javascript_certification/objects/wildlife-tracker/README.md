# Wildlife Tracker - Learning Project

## Overview
This project demonstrates JavaScript object manipulation using multiple approaches.

## Architecture

- animals.js → Data layer
- operations.js → Business logic
- app.js → Execution layer

---

## Key Concepts

### 1. Mutation vs Immutability
- Mutation modifies original objects
- Immutability creates new objects

Preferred: Immutability (safer and predictable)

---

### 2. Function Design
- Specific functions → readable
- Generic functions → reusable

---

### 3. Property Access
- Dot notation → simple
- Bracket notation → dynamic

---

### 4. Property Checking
- hasOwnProperty → older
- Object.hasOwn → modern and safer

---

## Learning Goal
Understand trade-offs between:
- Simplicity vs flexibility
- Performance vs safety
- Readability vs abstraction
